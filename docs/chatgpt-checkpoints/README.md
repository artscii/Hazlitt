## Updating checkpoints

Create a dated checkpoint after substantial work or before moving sessions. Record the source commit, application version, approved decisions, verification evidence, outstanding work and deployment state. Preserve older checkpoints. Keep passwords, tokens, cookies, private database exports and personal visitor data out of this folder.

Documentation-only updates do not require an application version increment or VPS container rebuild.
